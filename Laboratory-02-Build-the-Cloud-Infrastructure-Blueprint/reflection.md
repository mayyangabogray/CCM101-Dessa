# Laboratory 02 Reflection - Build the Cloud Infrastructure Blueprint

## 1. Key Learnings
Through this laboratory, I gained a deeper understanding of how physical and virtual cloud resources function. By investigating a live KillerCoda Linux server, I learned how to identify essential infrastructure components—such as compute cores, storage partitions, and network IP interfaces—firsthand.

## 2. Challenges & Solutions
One initial challenge was understanding how local server metrics translate into broader cloud architecture concepts. This was resolved by systematically analyzing commands like `free -h` and `df -h` to correlate them with professional cloud storage and compute resource models.

## 3. Practical Value
Building this blueprint demonstrated that regardless of the cloud provider (AWS, Azure, or GCP) or local testing environment (KillerCoda), the underlying fundamentals of computing, networking, and storage remain consistent. This knowledge is vital for designing scalable and efficient cloud infrastructures.
